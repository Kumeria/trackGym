# trackGym

Diario alimentare gestito con Claude Code. File + git come memoria.

- Regole per Claude: [`CLAUDE.md`](CLAUDE.md)
- Target e profilo: [`profile.yaml`](profile.yaml)
- Catalogo alimenti: [`foods/foods.json`](foods/foods.json)
- Diario: `log/AAAA/MM/AAAA-MM-GG.yaml`
- Report: `reports/`

Requisiti: Python 3.10+, PyYAML. Test: `python3 -m unittest discover -s scripts/tests`.
